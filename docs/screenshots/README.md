Para acrescentar uma galeria posteriormente:

1. Capturar o aplicativo real no Nintendo Switch, identificando versão/commit, modelo e ambiente de execução.
2. Usar nomes como `01-paineis.png`, `02-selecao-multipla.png` e `03-fila-local.png` somente quando os arquivos existirem.
3. Registrar aqui uma tabela com arquivo, tela, origem e versão. Manter as proporções originais; não montar uma UI fictícia.
4. Rever a imagem para remover da publicação tokens, credenciais, códigos OAuth, dados pessoais e nomes privados. Preferir capturar com dados fictícios preparados no console.
5. Adicionar legenda e texto alternativo ao README; indicar separadamente o que a captura demonstra e o que ainda não foi testado.

Não usar logotipos como capturas, screenshots de outro gerenciador, mockups ou imagens geradas por IA. As prévias do README feitas no navegador durante esta missão são evidências da documentação, não telas do aplicativo.
