SWITCH FILE MANAGER v0.10.3 — CORRECAO FTP + JANELAS
===================================================

Repositorio: https://github.com/TemudjinBR/switch-file-manager

PUBLICAR COM O CELULAR (MESMO METODO DAS VERSOES ANTERIORES)

1. Descompacte este arquivo no smartphone Android.
2. Abra https://github.com/TemudjinBR/switch-file-manager/upload/main
3. Selecione estes CINCO arquivos extraidos e envie todos na raiz:
   - Makefile
   - wifi_transfer.cpp
   - wifi_transfer.h
   - apply_ftp_update.py
   - CHANGELOG-v0.10.3.md
4. Confirme Commit changes.
5. Abra https://github.com/TemudjinBR/switch-file-manager/actions
   e baixe o artefato SwitchFileManager.nro se a compilacao concluir.
6. Substitua o NRO antigo no SD pela versao compilada para testar.

Nao envie o ZIP inteiro como se fosse um arquivo de codigo no GitHub.
Nao substitua manualmente main.cpp: apply_ftp_update.py atualiza essa
parte antes da compilacao. A versao 0.10.3 e gerada pelo Makefile.

NO SWITCH
  Acoes > Transferencia Wi-Fi > Iniciar FTP.
  Aparece ftp://IP-DO-SWITCH:2121.
  Manter ativo deixa servidor ligado, Parar servidor FTP o desliga.

NO CELULAR
  Abra gerenciador com suporte a FTP, protocolo FTP sem TLS/SSL.
  Endereco: IP mostrado pelo Switch.
  Porta: 2121.
  Login: Anonimo (sem senha).
  Preferir modo passivo; agora modo ativo tambem e aceito.

A tela do Switch agora apresenta clientes conectados e listagens.
Se o Android mostrar vazio, verifique no Switch se esses contadores
mudam; isso permite identificar se o cliente estabeleceu conexao FTP
ou se falhou antes de pedir a listagem.

TESTADO LOCALMENTE: compilacao isolada C++ em Linux, operacoes FTP
em modos ativo e passivo com dois clientes simultaneos, stop imediato.

NAO TESTADO: build devkitA64 real no GitHub Actions, Switch Lite fisico,
cliente FTP Android. Essas etapas dependem do novo artefato NRO.

SEGURANCA: acesso anonimo integral ao SD enquanto ativo;
use apenas rede confiavel e desligue ao terminar.
