SWITCH FILE MANAGER v0.10.2 - ATUALIZACAO FTP
=============================================

Repositorio: https://github.com/TemudjinBR/switch-file-manager
Destino no GitHub: raiz da branch main

PARA PUBLICAR PELO CELULAR (CAMINHO JA USADO NAS VERSOES ANTERIORES)

1. Extrair este ZIP no celular.
2. Abrir https://github.com/TemudjinBR/switch-file-manager/upload/main
3. Selecionar os arquivos Makefile, wifi_transfer.cpp, wifi_transfer.h,
   apply_ftp_update.py e CHANGELOG-v0.10.2.md, todos para a RAIZ.
4. Confirmar 'Commit changes'. O GitHub Actions existente sera acionado.
5. Conferir resultado em https://github.com/TemudjinBR/switch-file-manager/actions
   e, se a compilacao terminar com sucesso, baixar o artefato NRO.

IMPORTANTE:
- Nao enviar o ZIP compactado como um unico arquivo ao repositorio:
  e necessario enviar os arquivos internos.
- Nao substituir a pasta .github nem o arquivo main.cpp manualmente.
- A versao 0.10.2 no Homebrew e gerada pelo Makefile, que executa
  automaticamente apply_ftp_update.py antes da compilacao.
- Sem recompilacao/instalacao do NRO, o servidor antigo HTTP permanece ativo.
- FTP usa cliente FTP (ex.: gerenciador de arquivos Android), nao navegador.
- Endereco exibido pelo Switch: ftp://IP-DO-SWITCH:2121
- FTP anonimo sem senha; inicia por comando, para pelo menu ou quando sair.

VALIDADO AQUI:
- Compilacao isolada do servidor C++17 em Linux com simulacao de libnx.
- Testes reais de protocolo FTP no host (ftplib): conectar, listar,
  criar pasta, enviar, baixar, sobrescrever, renomear, excluir e parar.
- Teste de interrupcao de upload com limpeza de arquivo parcial.
- Script apply_ftp_update.py passou em verificacao de sintaxe e em teste
  de idempotencia sobre uma amostra das funcoes atuais.

AINDA PENDENTE:
- Compilacao real do projeto com devkitA64 via GitHub Actions.
- Teste fisico no Switch Lite / Atmosphere e em gerenciador FTP Android.
