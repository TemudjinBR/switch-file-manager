# Switch File Manager 0.10.14 — experimental

- **+** Menu sempre abre Arquivos e pastas, Transferências, Organização, Sistema e Sobre.
- X Ações é exclusivamente contextual; − Sair pede confirmação e aguarda encerramento seguro.
- SD/Drive: + Menu → Arquivos e pastas → Alternar microSD / Google Drive neste painel.
- Sobre usa a arte oficial em 256×256 nativos, informações reais e QR de apoio opcional abaixo. Sistema sem atalhos duplicados.
- Preservados OAuth, FTP 2121, ZIP, dois painéis, dados e logotipo. Não há fila universal nem retomada de upload nova.

Instalar os dois NROs do ZIP na pasta switch/Switch File Manager com o aplicativo fechado, fazendo backup dos executáveis anteriores. Não apagar configurações, credenciais ou arquivos ocultos. Conferir 0.10.14/build do manifesto e rodapé + Menu / X Ações / − Sair.

Validação automatizada/compilação não substituem homologação física. PENDENTE DE TESTE FÍSICO no Switch Lite. Sem merge ou Release nesta missão. [Guia Android](../docs/VERSAO_E_INSTALACAO.md) e [checklist](../docs/MENU_CONTEXTUAL.md).
